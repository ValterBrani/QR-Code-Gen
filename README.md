# QR Code Generator

[🇫🇷 Français](README.fr.md) | 🇬🇧 English

## Features

- Generate QR codes from text or URLs
- Advanced options (size, error correction level, colors)
- Download as PNG, JPG, or SVG
- Show/hide options panel
- Keyboard shortcut: `Ctrl+Enter` (or `Cmd+Enter`) to generate

## Run the Project

### Simple option
1. Open `index.html` in a browser.

### Recommended option (local server)
If you have Node.js:

```bash
npx serve .
```

Then open the displayed URL (usually `http://localhost:3000`).

## External Dependency

This project uses the `qrcodejs` library via CDN:

- https://cdnjs.cloudflare.com/ajax/libs/qrcodejs/1.0.0/qrcode.min.js

## Notes

- 100% front-end project, no backend.
- No build step is required.
